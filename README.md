# 📝 To-Do List CLI

A simple **command-line To-Do List** built with Python.

## Features

* Add tasks
* View tasks
* Delete tasks
* Save tasks using a text file
* Handle invalid input

## Concepts Used

* Python functions
* Lists
* Loops
* File handling
* Exception handling

## Run

```bash
python3 todo.py
```

Built as a Python practice project to improve **logic and file handling**.
